# AI CLI Setups Backup

This repository contains the complete setup guides and configuration files for two powerful AI CLI environments on Android/Termux.

## 🚀 Mistral Setup (Vibe/OpenClaw)
Located in `mistral-setup/`.
Includes:
- Full installation summary (`MISTRAL_SETUP_SUMMARY.md`).
- Voice control scripts (`mistral_voice_control.py`).
- Integration tests (`mistral_test.py`).
- Setup for Ollama, Mistral-7B, and various MCP servers.

## ♊ Gemini CLI Setup
Located in `gemini-setup/`.
Includes:
- Project configuration (`GEMINI.md`).
- Maestro Agent roles (`maestro_agents.txt`).
- MCP server configurations (`mcp.json`).
- Global rules (`.geminirules`).
- Integration with ATXP and Conductor.

## 🛠️ Installation
To restore these setups, refer to the respective summary files in each directory.
